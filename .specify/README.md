# Fluxo Spec-Driven Development

A fonte de verdade é [spec.md](../spec.md). O [plan.md](../plan.md) traduz a especificação em decisões técnicas e o [tasks.md](../tasks.md) decompõe a implementação em tarefas rastreáveis.

Antes de solicitar código ao agente, informar IDs dos requisitos, Issue e critérios de aceite. Revisar a alteração, executar testes e registrar o resultado real no PR. Se houver divergência, corrigir o código ou revisar a especificação antes do merge. Não registrar testes ou contribuições que não ocorreram.

Esta pasta contém convenções do projeto; não afirma que uma ferramenta externa Spec Kit ou integração MCP de codificação esteja instalada.
