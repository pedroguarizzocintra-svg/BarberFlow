# Guia de desenvolvimento

Siga as instruções atualizadas do [README](../README.md). Use Python 3.12, banco local em instance/ e senha fictícia. O comando init-db é não destrutivo, mas não constitui sistema de migrações. Para iniciar um banco limpo, utilize outro arquivo de banco ou faça backup antes de qualquer remoção manual. Consulte [testes](testing.md), [revisão](review/README.md) e [demonstração](delivery.md).
